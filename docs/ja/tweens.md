## トゥイーン

*グラフィカルな結果のためのオブジェクトのアニメーション。* **時間とともに値を補間する** — 位置やサイズから色や不透明度まで、トゥイーンは始点と終点を取り、その間のすべての値を生成します。だからこそ動きは飛び跳ねず、滑らかに読めます。

これがこのサイトのBetweenJSの中核です: トゥイーンは、サイト自体が動く方法です。

### トゥイーンは何でできているか

- **From / to の値** — アニメーションするプロパティの始点と終点（位置、不透明度、回転、色）。
- **持続時間** — 補間が実行される長さ。
- **イージング** — 動きを形作る曲線: ease in、ease out、quint、bounce、elastic。
- **ティッカー** — 時間を進め、補間された値を毎フレーム再適用するエンジン。

### なぜここでトゥイーンが重要か

BetweenJSはトゥイーンの周りに作られており、このサイトはその上で動いています。セクションは、サイト自身のアニメーションシステムが駆動するトゥイーンと*パラレル*なトゥイーンチェーンによって、スライドし、フェードし、スケールし、入れ替わります。

```js
// a tween, the way the site drives its own motion
BJS.tween(
    $section,                 // the element
    { marginTop: 0, opacity: 100 },   // to
    { marginTop: 150, opacity: 0 },   // from
    0.08,                     // seconds
    Quint.easeOut
);
```

### どこに位置づけられるか

- **BetweenJS** — トゥイーン、ディレイ、シリアル/パラレルチェーン、イージングファミリー、カラー補間。
- **トランジション** — サイトをナビゲートするときに見えるセクションとデッキの動き。
- **あらゆるインターフェース** — ホバー状態、リビール、マイクロインタラクションはすべて同じ考え方に還元されます。
