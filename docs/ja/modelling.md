## モデリング

*形を作るために用いられるワークフロー。* **ボックスモデリングからスカルプティング、リトポロジー、その先まで** — コンセプトカーから建築的なフォルムまで、このサイトの作品の背後にあるジオメトリを構築するための一連の規律です。

各プロジェクトは、その形に合うワークフローを選ぶ傾向があります。ハードサーフェスのオブジェクトはボックスモデリングし、有機的または詳細なパーツはスカルプトし、変形のためにクリーンなトポロジーが必要なものはリトポロジーします。

### 主なワークフロー

- **ボックスモデリング** — プリミティブ（立方体、球、円柱）から始め、押し出し、ベベル、ループカット、トランスフォームで形を整えます。速く、予測可能で、ハードサーフェスや製品フォルムに最適です。
- **スカルプティング** — 高密度メッシュを粘土のように扱い、表面のディテールを押し引きします。有機的な形、キャラクター、高ディテールのフォルムに最適です。
- **リトポロジー** — スカルプトまたはスキャンした表面の上に、アニメーションに適したクリーンなメッシュを再構築し、最終モデルがよく変形し、よくレンダリングされるようにします。
- **UVマッピングとレイアウト** — 表面を展開し、テクスチャ、マテリアル、シェーダーが形のどこに存在するかを把握できるようにします。

### なぜここで重要か

モデリングは、このサイトのすべての作品が始まる場所です — 屋根のフォルム、ボディライン、コンセプトの形。あなたが構築するジオメトリが、その先のすべてを決めます: トポロジー、UV、マテリアル、そしてレンダーやリアルタイムシーンでの振る舞いまで。

```blender
# example — a box-modelled workflow
1. Add a cube primitive
2. Loop cut (Ctrl+R) to add resolution
3. Bevel edges for softened forms
4. Extrude (E) to build outwards
5. Apply a subdivision modifier for smoothness
```

### どこに位置づけられるか

- **作品** — 車、屋根、コンセプトピースはすべて、モデリングされたジオメトリから始まります。
- **プロシージャル** — 一部の形は手で作るのではなく生成され、その後同じパイプラインで表面化されテクスチャが貼られます。
- **シェーダー** — 最終的なメッシュはシェーダーが動く対象です。トポロジーとUVがマテリアルの乗り方を決めます。
