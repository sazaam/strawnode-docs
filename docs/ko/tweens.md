## 트윈

*그래픽 결과를 위해 객체를 애니메이션하는 것.* **값을 시간에 따라 보간합니다** — 위치와 크기부터 색과 불투명도까지, 트윈은 시작값과 끝값을 받아 그 사이의 모든 값을 만들어 냅니다. 그래서 움직임이 뚝뚝 끊기는 대신 부드럽게 읽힙니다.

이 사이트에서 그게 BetweenJS의 핵심입니다. 트윈은 곧 사이트가 스스로 움직이는 방식입니다.

### 트윈은 무엇으로 이루어지는가

- **시작/끝값** — 애니메이션되는 프로퍼티의 시작과 끝(위치, 불투명도, 회전, 색).
- **지속시간** — 보간이 진행되는 시간.
- **이징** — 움직임의 모양을 만드는 곡선: ease in, ease out, quint, bounce, elastic.
- **티커** — 시간을 진행시키고 매 프레임 보간된 값을 다시 적용하는 엔진.

### 왜 여기서 중요한가

BetweenJS는 트윈을 중심으로 만들어졌고 — 이 사이트는 바로 그것 위에서 돌아갑니다. 사이트 자체의 애니메이션 시스템이 구동하는 트윈과 *병렬* 트윈 체인으로 섹션이 밀려 들어오고, 페이드하고, 스케일하고, 자리를 바꿉니다.

```js
// a tween, the way the site drives its own motion
BJS.tween(
    $section,                 // the element
    { marginTop: 0, opacity: 100 },   // to
    { marginTop: 150, opacity: 0 },   // from
    0.08,                     // seconds
    Quint.easeOut
);
```

### 어디에 맞는가

- **BetweenJS** — 트윈, 딜레이, 직렬/병렬 체인, 이징 패밀리, 컬러 보간.
- **전환** — 사이트를 탐색할 때 보게 되는 섹션과 데크의 움직임.
- **어떤 인터페이스든** — 호버 상태, 리빌, 마이크로 인터랙션 모두 결국 같은 아이디어로 수렴합니다.
